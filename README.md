# Mini To-Do App
A simple and responsive To-Do application built with **HTML, CSS, and JavaScript**.

## Features
* Add and delete tasks
* Mark tasks as completed
* Task and completed-task counter
* Tasks saved using `localStorage`
* Responsive modern UI

## Tech Stack
* HTML
* CSS
* JavaScript
* LocalStorage

## Live Demo
https://mini-to-do-app-nu.vercel.app/

## Run Locally
Open `index.html` in your browser or use VS Code Live Server.
